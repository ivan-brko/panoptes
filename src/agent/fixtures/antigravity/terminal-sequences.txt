# The kitty stack is popped and re-pushed around the alt-screen exit, so it stays
# balanced (depth 1). The main UI then draws inline on the primary screen.

## Steady state

# session). OSC 8 hyperlinks (\x1b]8;id=...;file://...\x07) are used for paths.
